了解每个工具的定位和使用场景

📎 ✦
📦

aweskill

AI agent 技能包管理器。让你的 Claude agent 能力像 npm 包一样安装、打包和分发。支持跨 agent 兼容，内置健康检查。

GitHub → npm 文档
🔀

aweswitch

Agent 配置切换器。为不同项目或场景保存独立的 Claude Code 配置，一键切换模型、权限、环境变量。

GitHub → npm 文档
👥

aweteam

AI 编程团队协调器。在 tmux 中启动 leader-worker 多 agent 协作，对话保留在各自的 pane 中，可追踪、可审查。

GitHub → npm 文档
